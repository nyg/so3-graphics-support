# Graphics Support in SO3

English edition of my Bachelor thesis *Support graphique dans SO3* (HEIG-VD, 2020), published at <https://nyg.github.io/so3-graphics-support>.

It is a [Quarto](https://quarto.org) book. Preview it locally with:

```bash
quarto preview
```

Every push to `master` renders the HTML site and the PDF, and deploys them to GitHub Pages.

The original French LaTeX and Sphinx sources are in [nyg/so3-support-graphique](https://gitlab.com/nyg/so3-support-graphique).
